# Crayon Company Guide

从零看懂一家公司，比较真正影响求职选择的信息。

这是一个面向求职者的 Agent Skill，把猎头研究和介绍公司的方法整理为可重复使用的调研流程。你可以在面试前了解公司，也可以在拿到多份 Offer 后比较岗位、团队、成长与风险。

## 能做什么

- **单公司了解**：解释公司做什么、谁付钱、发展阶段、创始人与团队、融资和规模、行业位置、岗位价值与风险。
- **单份 Offer 核验**：进一步关注签约主体、汇报关系、试用期、绩效、薪酬、工作条件和职业路径。
- **多份 Offer 选择**：按同一套七维框架比较，结合你的优先级给出条件式建议。
- **普通公司比较**：还没拿到 Offer 时也可以比较公开的公司和岗位信息。

不懂行业术语也可以使用。公司业务先解释准确，再用大白话与比喻辅助理解。

## 三种输出，自己选

| 输出 | 适合怎样阅读 | 信息深度 |
| --- | --- | --- |
| HTML 可视化报告 | 用导航、卡片、矩阵查看 | 完整调研 |
| 详细文档版 | 阅读结构化长文、存档 | 完整调研 |
| 简单文字版 | 快速掌握关键点 | 精简调研 |

HTML 和详细文档研究范围相同。未指定输出时，Skill 会先请你选择；已经提供岗位方向或输出形式时，不会重复询问。求职阶段只影响关注点，不自动决定篇幅。

详细文档默认是结构化长文。Word / PDF 导出需要你所用工具具备相应能力；HTML 生成需要工具能写文件。实时公司调研需要联网检索；无法核验的信息会保留为待确认。

## 安装

将整个仓库目录导入支持 Agent Skills 的工具，保留 `SKILL.md`、`agents/` 和 `references/` 的相对位置。只复制 `SKILL.md` 会丢失完整的多 Offer 比较规则。

在 Codex 中，也可以请它安装：

```text
请安装 https://github.com/wangranm-a11y/crayon-company-guide 里的 Skill。
```

已有本地 Skill 目录约定的环境，可把完整目录放入相应的 `skills/crayon-company-guide/`。不同工具对 Skill 的加载与调用方式不同，请按该工具的安装入口导入。

## 调用示例

### 从零了解公司

```text
使用 $crayon-company-guide，帮我调研杭州深度求索。
我想投 AI 产品经理，输出 HTML 可视化报告。
```

还没想好岗位也可以：

```text
使用 $crayon-company-guide，帮我看懂这家公司。
我还没想好岗位，只是先了解公司，选择简单文字版。
```

### 比较多份 Offer

把下面示例替换为你自己的公司、岗位和已知条件。输入越具体，岗位和团队层面的判断越有帮助；未知项可以直接写“不知道”。

```text
使用 $crayon-company-guide，我已经拿到了两份 Offer，帮我比较怎么选。

Offer A：公司、岗位、地点、固定薪资、奖金、期权、直属领导、团队及其他已知条件。
Offer B：公司、岗位、地点、固定薪资、奖金、期权、直属领导、团队及其他已知条件。

我最在意成长、直属领导和长期职业路径，输出 HTML 可视化报告。
请区分公开事实、书面条件、口头承诺和待确认事项。
```

多 Offer 模式会比较：

1. 公司与业务前景
2. 岗位核心程度
3. 直属领导与团队
4. 成长与履历价值
5. 薪酬与兑现确定性
6. 工作强度与现实成本
7. 稳定性与风险

它默认不打总分。结论会说明每份 Offer 更适合谁、哪些条件成立时更值得选择，以及哪些信息可能改变建议。关键证据不足时，可以暂不排序。

## 工作方式与边界

这是指导 AI 执行研究的 Skill，不是独立运行的招聘网站、公司数据库或自动决策程序。结果取决于所用模型、检索工具、公开资料和用户输入，需要核对重要事实。

薪酬口头承诺不等于书面条件；用户转述的书面条款会注明原文未核验。融资、估值或媒体热度不会直接被当作稳定性证明。Skill 不代替你接受或拒绝 Offer，也不提供专业法律、税务或投资结论。

HTML 使用复古绿、浅粉、暖白配色，内联 CSS / JS 和系统字体，不依赖作者电脑上的模板或外部图床。
